# Turning Point Liberia

A website for Turning Point Liberia, a youth-led initiative creating practical pathways through skills, mentorship, opportunity, and partnership.

## Tech stack

- React
- Vite
- React Router

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The production files are generated in the `dist` directory.

## Project settings

Update contact details and the registration link in [`src/config.js`](./src/config.js).
